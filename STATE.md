## What's in place

- **Marketing pages** (all 4 apps): hero, sample output, how-it-works, "for who / not for", pricing, FAQ, final CTA
- **OG images** (1200×630 PNG): 4 apps + root + apple-icon (32×32) + favicon (180×180) — all auto-generated by Next.js `ImageResponse`
- **Legal pages**: `/privacy`, `/terms` (linked from footer + signup agreement)
- **Help docs**: `/help` with per-app FAQ
- **SEO**: `sitemap.xml` (7 URLs), `robots.txt` (disallows `/api`, `/account`, per-app detail pages), metadataBase, canonical, og:*, twitter:*
- **Analytics**: Vercel Web Analytics (script auto-injects in browser)
- **Error pages**: `error.tsx` + `global-error.tsx` + `not-found.tsx` with friendly copy and "try again"
- **Stripe** (test mode wired, needs real test keys to enable):
  - `/api/billing/checkout` (POST → Stripe Checkout session)
  - `/api/billing/portal` (POST → Stripe billing portal)
  - `/api/billing/webhook` (POST → handles 3 event types, uses `sub.items.data[0].current_period_end` per Stripe API v22)
  - Free-tier enforced via `canUseApp(userId, app)` in `src/lib/limits.ts` (returns 402 + `needsSubscription: true`)
  - `/account` page shows all 4 apps with usage + pricing cards + subscribe/manage buttons
- **Resend** (needs real key to enable):
  - `src/lib/email.ts` with `sendWelcomeEmail`, `sendPaymentReceiptEmail`, `sendSubscriptionCanceledEmail`, `sendStillHereSundayDigest`
  - Hooks: signup → welcome; Stripe webhook → receipt on `checkout.session.completed`; cancel → "access until X" email
  - Sunday digest cron at `/api/cron/still-here-digest` (vercel.json: Sun 13:00 UTC). Sends digest to users with friends not contacted in 30+ days
- **Auth**: jose JWT (48-byte secret in env), bcryptjs, session cookie, `/api/auth/logout`
- **OpenRouter**: `anthropic/claude-3.5-haiku` as default. Latency 3-13s.
- **Prisma**: SQLite local dev + Postgres prod (schema swap in `vercel.json` buildCommand). Lazy `Proxy` pattern in `src/lib/db.ts` so app loads 200 even if DB unconfigured.
